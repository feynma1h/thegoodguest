# Photos

This directory is for test/development photos. Place 3-9 room photos here for
inference testing via `tools/call_perception.py`.

Supported formats: JPG, JPEG, PNG, HEIC, HEIF.

For best multi-view reconstruction results, capture from 4+ different positions
covering all walls of the room. See the conversation notes for guidance on
shooting patterns.

This file (`README.md`) is a placeholder so the empty directory is included in
version control. Photo files themselves should generally not be committed if
they're large; consider adding `*.jpg`, `*.heic` etc. to .gitignore if so.
